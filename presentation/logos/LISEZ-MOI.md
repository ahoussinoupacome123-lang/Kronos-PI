# Logos des opérateurs

Déposez ici les logos officiels, sous ces noms exacts :

| Fichier | Opérateur |
|---|---|
| `moov.png` | Moov Africa |
| `mtn.png` | MTN MoMo |
| `wave.png` | Wave |

PNG ou SVG renommé en `.png` refusé : gardez le vrai format et, pour un SVG, changez `src="logos/xxx.png"` en `.svg` dans `kronospi.html`.

Tant qu'un fichier manque, la présentation affiche une pastille aux couleurs de l'opérateur à la place du logo.

Les logos restent la propriété de leurs titulaires : ils servent ici d'illustration d'un scénario sur données synthétiques, sans partenariat revendiqué.
